# Анализ поступления абитуриентов (Rust)

## Описание
Программное обеспечение для автоматизированного анализа
конкурсных списков приёмной кампании ВУЗа.

Система:
- загружает конкурсные списки
- обновляет данные в PostgreSQL
- рассчитывает проходные баллы
- учитывает приоритеты абитуриентов

## Технологии
- Rust
- PostgreSQL
- SQLx
- Tokio

## Алгоритм обновления данных
При загрузке нового дня:
- удаляются абитуриенты, отсутствующие в новом списке
- добавляются новые абитуриенты
- обновляются существующие записи
Приоритет отдаётся последнему загруженному дню.

## Алгоритм расчёта проходного балла
- учитываются только абитуриенты с согласием
- абитуриент может быть зачислен только на одну программу
- учитываются приоритеты (1–4)
- проходной балл — балл последнего зачисленного

## Генерация данных
Для тестирования используются сгенерированные конкурсные списки
с динамикой изменения состава абитуриентов.
